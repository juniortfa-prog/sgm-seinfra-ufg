# Critérios mínimos antes de publicar a aplicação completa

**Visual:** verificar todos os 23 módulos originais, o Kanban, menus, gráfico de resultados, Balanço de OS e versão móvel. Usar capturas privadas da V54.9 como referência.

**Dados:** manter IDs e consolidação. O total de pendentes deve ser a soma das situações mutuamente exclusivas para o mesmo corte; classificações H1/H2/H3 são outro recorte. OS sem informações ficam contabilizadas.

**Execução:** concluir diminui saldo sem apagar registro; reabrir restaura. Programação pelo Kanban atualiza roteiros. Refrigeração sem capacidade não desaparece do passivo; preventivas adiadas mantêm registro. Aprovação somente por perfis autorizados.

**Segurança:** OS não podem aparecer em arquivos públicos; RLS e autorização devem impedir leitura/alteração por usuário sem permissão; nunca colocar credenciais secretas no navegador; registrar auditoria.

**Entrega:** testar múltiplas sessões, edição concorrente, nova importação e rollback. A versão temporária da produção permanece até aprovação formal.
